# Rota releases

Release builds of Rota, a personal gym log for Android by Rumination Labs.

This repository only hosts the APK files. The app checks the latest release on launch and offers the update in a pop-up. No workout data is stored here: everything stays on the phone.

## Install

1. On the phone, open the latest release under **Releases** and download `rota-<version>.apk`.
2. Open the downloaded file and allow installs from your browser or file manager when Android asks.
3. Later versions install from inside the app.
